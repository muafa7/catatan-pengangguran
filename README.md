# Catatan Pengangguran

> An unemployed engineer's learning diary.

I'm currently between jobs, and this repository is where I keep notes on things I learn, build, debug, misunderstand, and eventually understand a little better.

This is not meant to be a polished tutorial collection or a structured curriculum.

The entries can be anything:

* notes from courses
* things I tried while building something
* debugging stories
* concepts that finally clicked
* random technical rabbit holes
* mistakes in my mental model
* useful things I don't want to forget

I'm currently spending a lot of time around software engineering and DevOps, but I'm not limiting the repository to any particular topic.

## Structure

Entries are organized by year and month.

```text
2026/
└── 09/
    ├── 2026-09-01-docker-networking.md
    ├── 2026-09-02-linux-processes.md
    └── ...
```

There is no strict format for an entry.

Some might be detailed.
Some might just be a few paragraphs about something that clicked.

The goal is simply to keep learning and leave a trail of what I was thinking along the way.

## Why "Catatan Pengangguran"?

It roughly translates to **"Unemployment Notes"** in Indonesian.

The name is a joke.

The learning isn't.
